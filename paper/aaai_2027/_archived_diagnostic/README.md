# Archived: pre-DT-ATACOM diagnostic drafts

These materials were generated before the 2026-05-18 pivot to the
DT-ATACOM algorithm framing. They reflect three earlier framings that
are no longer used by `main_v2.tex`:

1. **`sections/`** — the original diagnostic-only narrative ("we found
   the failure modes; here is the taxonomy"). Replaced by `sections_v2/`
   which uses the "we propose an algorithm" framing.
2. **`SELECTED.md`, `SELECTED_AAAI_TAXONOMY_PIVOT.md`,
   `SELECTED_ORIGINAL_PRCF.md`** — earlier paper-structure pivots
   (PRCF-only → taxonomy-only). Superseded by `PAPER_STRUCTURE_v2.md`.
3. **`proposals/`** — algorithm proposals (PRCF revival, AMRF, IICF,
   distillation, velocity-aware). IICF/PRCF were tried and shelved as
   negative results; DT-ATACOM replaces them as the §IV algorithm. The
   per-proposal DESIGN.md files are retained for reference.

Files in this directory are not built by the current AAAI 2027 paper
pipeline. They may be referenced for context or future revisions but
should not be edited.

Pivot context: see `safe-rl-2027/STATUS.md` §6.1 (2026-05-18 entry) and
the main paper's §I + §IV-C Proposition 4.
