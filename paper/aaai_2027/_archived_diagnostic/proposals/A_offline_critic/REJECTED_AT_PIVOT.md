## 1. One-line summary
Train an HJ-reachability safety critic $Q_c(s,a)$ from offline data
using IQL-style expectile regression, then enforce safety at runtime
by solving a small QP that minimally projects each policy action onto
the level set $\{a:Q_c(s,a) \le \epsilon\}$.

## 2. AAAI fit and positioning

### Why this is the strongest AAAI direction
- **Honest theory.** Both ingredients (IQL expectile regression for
  offline value learning, CBF-style action projection) are
  individually established. The contribution is the *composition*:
  the safety critic learned offline replaces the analytical CBF
  certificate that constrained-RL methods such as ATACOM, PPO-Lag,
  and CPO need at design time.
- **Matches the paper claims.** The IROS2026 paper already promises
  "offline HJ-reachability + manifold filter"; here we actually build
  exactly that. No method/implementation gap.
- **Strong empirical story.** The offline-RL trend (IQL, CQL,
  Decision Transformer) makes this a natural fit; 2026 AAAI
  reviewers will recognise the techniques and care about the
  composition.
- **Hot baselines available.** ATACOM, CPO, PPO-Lag, CBF-QP all
  reproducible.

### Positioning vs. closest related work
- **vs. ATACOM (Liu 2022):** ATACOM derives a null-space projection
  from analytical constraint Jacobians. We replace those Jacobians
  with a learned $Q_c(s,a)$ that handles non-trivial / non-affine
  constraints and observable-only state.
- **vs. CBF-QP (Ames 2014, Choi 2020):** CBF-QP needs a hand-crafted
  Lyapunov function. Our $Q_c$ is data-driven.
- **vs. CPO / PPO-Lag (Achiam 2017, Stooke 2020):** They use *soft*
  constraints with Lagrange multipliers; we keep a hard projection.
- **vs. neural CBFs (Robey 2020, Dawson 2022):** They learn a CBF
  *online* from rollout data; we learn it *offline* once and reuse.

## 3. Method

### 3.1 Offline data
A modest dataset $\mathcal{D} = \{(s_t, a_t, c_t, s_{t+1})\}_{t=1}^{N}$,
$N=10^5$. Generated by:
1. Random exploration of the env (50 K transitions) — easy data.
2. Pre-trained PPO rollouts (50 K transitions) — informative data.

### 3.2 Safety critic learning (IQL + HJ Bellman)

We learn two networks:
- $V_c(s)$ — feasibility value, $V_c(s) \le 0 \Leftrightarrow s$ is feasible.
- $Q_c(s,a)$ — feasibility action-value.

Targets follow the discounted HJ Bellman backup
$$T^* Q_c(s,a) = (1-\gamma) c(s) + \gamma \,\max\bigl(c(s),\, V_c(s')\bigr).$$

Updates with expectile regression (IQL, Kostrikov 2022):
$$\mathcal{L}_V = \mathbb{E}_{\mathcal{D}} \bigl[ L_2^{\tau}\bigl(Q_c(s,a) - V_c(s)\bigr) \bigr],$$
where $L_2^{\tau}(u) = |\tau - \mathbb{1}[u<0]|\,u^2$ with $\tau \in (0.5, 1)$.
$$\mathcal{L}_Q = \mathbb{E}_{\mathcal{D}} \bigl[ \bigl(Q_c(s,a) - T^* Q_c(s,a)\bigr)^2 \bigr].$$

This is exactly the formulation in the existing
`reachability.py`; we will productionise it.

### 3.3 Runtime safety filter (CBF-QP via $Q_c$)

At each control step:
$$a_{\text{safe}} = \arg\min_{a \in \mathcal{A}} \tfrac{1}{2}\|a - a_{\text{unsafe}}\|^2$$
$$\text{s.t.} \quad Q_c(s, a) \le \epsilon, \quad \|a\|_\infty \le 1.$$

Solved by SLSQP (already implemented in
`safe_rl/filters/cbf_qp.py`) with one inequality constraint per
state. Empirical latency expected ≈ 5–10 ms/step on CPU.

If the QP is infeasible (very rare with $\epsilon > 0$), we fall back
to the analytic null-space projection (`ManifoldFilter`) as a
recovery action.

### 3.4 PPO integration

Standard PPO loop with the above filter wrapping the action:
- Policy outputs $a_{\text{unsafe}}$.
- Filter returns $a_{\text{safe}}$.
- Environment receives $a_{\text{safe}}$; PPO buffer stores
  $a_{\text{unsafe}}$ (so the policy gradient remains intact).
- Optional reward calibration $R - \lambda\|a_{\text{unsafe}} -
  a_{\text{safe}}\|^2$ (the ATACOM form).

## 4. Theory

### Theorem 4.1 (Critic convergence under coverage)
Let $\pi_\beta$ be the offline behaviour policy and $\rho_\beta$ its
state distribution. Assume $\rho_\beta$ has full support on
$\mathcal{S}$ and the function class is sufficiently expressive.
Then for $\tau \to 1^-$ and $N \to \infty$,
$V_c \to V_c^*$ in $L_2(\rho_\beta)$, where $V_c^*$ is the optimal HJ
feasibility value.

*Proof sketch.* Direct application of Kostrikov 2022 Theorem 1 to the
HJ Bellman operator. The key observation is that the HJ operator is a
$\gamma$-contraction in $L_\infty$, identical structure to the
standard Bellman operator that IQL handles.

### Theorem 4.2 (Filter safety bound)
Let $\hat Q_c$ satisfy $\sup_{(s,a)} |\hat Q_c(s,a) - Q_c^*(s,a)|
\le \delta$. Then any state $s_t$ generated by following
$a_{\text{safe}}^{\hat Q_c}(\cdot)$ satisfies $c(s_t) \le \epsilon +
\delta + O(\Delta t)$ for sufficiently small step size $\Delta t$.

*Proof sketch.* The QP guarantees $\hat Q_c(s,a_{\text{safe}}) \le
\epsilon$. By the critic error bound, $Q_c^*(s,a_{\text{safe}}) \le
\epsilon + \delta$. Standard CBF-style argument (Ames 2014) bounds
the next-step constraint by the current value plus discretisation
error.

### Theorem 4.3 (PPO convergence preserved)
The augmented PPO loss using $a_{\text{safe}}$ in the environment but
$a_{\text{unsafe}}$ in the policy gradient retains the same
asymptotic optimality guarantees as standard PPO, provided the filter
is bounded $\|a_{\text{safe}} - a_{\text{unsafe}}\| \le M$.

*Proof sketch.* The action-value bias introduced by the filter is
$O(M)$, which is constant in PPO's iterate count. The PPO clip and
trust-region structure absorb this bias just as they absorb sampling
noise.

## 8. Risks and mitigations

| Risk | Likelihood | Mitigation |
|---|---|---|
| Offline IQL training is unstable on Safety-Gym data | Medium | Use the well-tuned IQL hyperparameters from Kostrikov 2022; if necessary fall back to vanilla TD on the HJ operator with a target network. Existing `reachability.py` already has the structure. |
| QP solver too slow for 200 K-step training | Low | SLSQP measured ≤ 10 ms/step on Phase 0 hardware. If too slow, switch to OSQP (precompiled C). |
| QP infeasible in cluttered scenes | Medium | $\epsilon > 0$ slack and the analytic ManifoldFilter fallback handle this; we already have the code. |
| Reviewers ask "why not just use neural CBFs" | High | Section II contrasts: neural CBFs need online rollouts, ours uses purely offline data. Add an explicit comparison row (small extra experiment). |
| ICRA paper depends on $Q_c$ being trained — synchronisation overhead | Low | $Q_c$ is task-agnostic given fixed obstacle layout, so the ICRA Webots paper just imports the AAAI-trained checkpoint. |
